# 第10课：结构体——把不同类型打包

> **老师**：数组只能存同类型的数据。但一个学生有姓名（字符串）、年龄（整数）、成绩（小数），怎么存？用**结构体**。

---

## 10.1 结构体是什么？

**结构体 = 档案袋**
- 档案袋里可以装不同东西
- 有名字、年龄、照片等

## 10.2 定义和使用

```c
struct Student {
    char name[20];
    int age;
    float score;
};

struct Student s1 = {"小明", 20, 85.5};
printf("%s", s1.name);  // 输出：小明
```
