# 第7课：数组——一排带编号的柜子

> **老师**：之前我们学了一个变量存一个数据。但如果要存 100 个学生的成绩，难道要定义 100 个变量吗？当然不用！用**数组**就行了。

---

## 7.1 数组是什么？

**数组 = 一排带编号的柜子**

- 柜子排成一排，每个柜子都有编号（下标）
- 编号从 0 开始！
- 所有柜子装同一种东西（同类型）

```c
int scores[5];  // 一排 5 个柜子，每个装整数
```

## 7.2 数组的定义和使用

```c
int a[5];          // 定义 5 个整数的数组
a[0] = 10;         // 第1个柜子放 10
a[1] = 20;         // 第2个柜子放 20
printf("%d", a[0]); // 输出 10
```

## 7.3 数组的初始化

```c
int a[5] = {10, 20, 30, 40, 50};  // 定义时初始化
int b[] = {1, 2, 3};               // 自动确定大小
```

## 7.4 数组和循环是好搭档

```c
int a[5] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    printf("%d ", a[i]);  // 逐个输出数组元素
}
```

## 7.5 字符数组和字符串

```c
char str1[] = "hello";     // 字符串
char str2[] = {'h','e','l','l','o','\0'};  // 和上面一样
```
