# 第5课：选择结构——让程序会判断

> **老师**：今天学的东西非常重要！学会 if-else，你的程序就不再是"一条路走到黑"了，而是会根据情况做不同的选择。

---

## 5.1 if 语句

**语法**：
```c
if (条件) {
    // 条件为真时执行的代码
}
```

**生活比喻**：如果下雨，就带伞
```c
if (下雨 == 真) {
    带伞();
}
```

---

## 5.2 if-else 语句

**语法**：
```c
if (条件) {
    // 条件为真时执行
} else {
    // 条件为假时执行
}
```

**生活比喻**：如果下雨就带伞，否则戴帽子
```c
if (下雨 == 真) {
    带伞();
} else {
    戴帽子();
}
```

---

## 5.3 多重 if-else if

**语法**：
```c
if (条件1) {
    // 条件1为真时执行
} else if (条件2) {
    // 条件1为假且条件2为真时执行
} else {
    // 全部为假时执行
}
```

---

## 5.4 switch 语句

适合多个固定值的情况：

```c
switch (表达式) {
    case 值1:
        // 代码
        break;
    case 值2:
        // 代码
        break;
    default:
        // 默认代码
}
```

## 课后练习

1. 输入一个整数，判断它是正数、负数还是零。
2. 输入一个年份，判断它是否是闰年（能被4整除但不能被100整除，或者能被400整除）。
3. 输入三个整数，输出最大的那个数。
4. 输入一个成绩（0-100），输出对应的等级：90-100为A，80-89为B，70-79为C，60-69为D，0-59为E。
