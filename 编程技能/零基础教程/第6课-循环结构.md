# 第6课：循环结构——让程序重复干活

> **老师**：计算机最擅长什么？重复做同一件事！今天我们就来学怎么让计算机循环干活。

---

## 6.1 while 循环

**语法**：先判断条件，条件为真就执行
```c
while (条件) {
    // 重复执行的代码
}
```

**例**：输出 1 到 5
```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i = i + 1;  // 别忘改 i，否则死循环！
}
```

---

## 6.2 for 循环（最常用）

**语法**：
```c
for (初始化; 条件; 更新) {
    // 重复执行的代码
}
```

**例**：输出 1 到 5
```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

for 循环将三个部分写在一起，更简洁。

---

## 6.3 break 和 continue

- **break**：跳出整个循环
- **continue**：跳过本次循环，进入下一次
