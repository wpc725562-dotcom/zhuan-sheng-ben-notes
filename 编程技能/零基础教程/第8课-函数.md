# 第8课：函数——把代码打包成积木块

> **老师**：写代码时，有些功能要重复使用。比如你要计算圆的面积好几次，难道每次都写一遍公式吗？用**函数**把代码打包成积木块，需要的时候直接调用。

---

## 8.1 函数是什么？

**函数 = 乐高积木块**
- 你搭好一个积木块（定义函数）
- 需要的时候直接拿过来用（调用函数）

## 8.2 函数的定义

```c
返回值类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}
```

**例子**：求两个数的和
```c
int add(int x, int y) {
    int sum = x + y;
    return sum;
}
```

## 8.3 函数的调用

```c
int result = add(3, 5);  // 调用函数，result = 8
```

## 8.4 函数的好处

1. **复用**：一次定义，多次使用
2. **模块化**：把大问题拆成小问题
3. **易维护**：改一个地方就行
