# 第1课：计算机是怎么工作的？

> **老师**：同学们好！今天是我们第一节课。在开始写代码之前，我们先要搞清楚计算机到底是怎么工作的。别担心，我会用最通俗的方式讲，保证你听得懂！

---

## 1.1 计算机的组成

一台计算机就像一个人：

| 计算机部件 | 人类比喻 | 作用 |
|:---|:---|:---|
| CPU（中央处理器） | 大脑 | 思考和计算 |
| 内存（RAM） | 便签纸 | 临时记住正在处理的事 |
| 硬盘 | 书架 | 永久存东西 |
| 键盘/鼠标 | 嘴巴/耳朵 | 输入信息 |
| 显示器 | 眼睛 | 输出信息 |

> 关键理解：CPU 从内存读数据 -> 计算 -> 把结果写回内存。硬盘是仓库，要用的东西先搬到内存（便签纸）上才能处理。

## 1.2 程序是什么？

**程序 = 一份菜谱**

- 菜谱告诉厨师（CPU）怎么做菜
- 程序告诉计算机做什么
- 菜谱是步骤，程序也是步骤

**例子**：煮方便面的程序
1. 烧水
2. 放面饼
3. 等3分钟
4. 放调料
5. 搅拌
6. 吃

计算机程序也是一样的逻辑，只不过用编程语言写。

---

## 1.3 编译 vs 解释

计算机只懂 0 和 1（二进制），但我们写的是 C 语言（人类能读懂的）。

**编译**：就像把中文书翻译成英文书
- 一次性翻译完 -> 生成可执行文件（.exe）
- C 语言就是编译型语言
- 优点：跑得快

**解释**：就像同声传译
- 边翻译边执行
- Python 是解释型语言
- 优点：灵活

## 1.5 第一个程序：Hello World

这是每个程序员的入门仪式，先跟着做，不用完全理解：

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

**逐行解释**：
- #include <stdio.h> -- 引入标准输入输出库（就像借工具）
- int main() -- 主函数，程序从这里开始执行
- printf(...) -- 输出文字到屏幕
- return 0; -- 告诉操作系统"程序正常结束"
- \n -- 换行符

> 老师：现在你可能看不懂，没关系！先记住 C 程序的"骨架"长这样就行。下一课开始，我们一点一点地学。
