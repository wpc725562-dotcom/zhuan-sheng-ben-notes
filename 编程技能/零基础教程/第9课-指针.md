# 第9课：指针——C语言的灵魂

> **老师**：指针是 C 语言最让人头疼的概念，但也是最重要的。别怕，用比喻来理解。

---

## 9.1 指针是什么？

**指针 = 门牌号**

- 你家有一个地址（门牌号）
- 别人知道这个地址，就能找到你家
- 指针就是变量的地址，通过指针可以找到变量

## 9.2 基本用法

```c
int a = 10;
int *p = &a;   // p 存了 a 的地址（门牌号）
printf("%d", *p);  // *p 通过地址找到 a 的值，输出 10
```

## 9.3 指针的作用

1. 函数间传递大块数据（不用复制整个数组，传地址就行）
2. 动态内存分配
3. 实现链表等数据结构
