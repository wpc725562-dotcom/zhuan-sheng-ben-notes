# 第4课：运算符——让计算机做计算

> **老师**：今天我们来学各种运算符。有了它们，计算机才能做真正的计算工作。

---

## 4.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|:---:|:---|:---:|:---:|
| + | 加 | 5 + 3 | 8 |
| - | 减 | 5 - 3 | 2 |
| * | 乘 | 5 * 3 | 15 |
| / | 除 | 5 / 2 | 2（注意！整数除法会舍去小数） |
| % | 取余（模） | 5 % 2 | 1 |

**整数除法的陷阱**：
```c
int a = 5 / 2;   // a = 2，不是 2.5！
float b = 5 / 2; // b = 2.0，还是 2！
float c = 5.0 / 2; // c = 2.5，对了！
```
要让除法得到小数，至少有一个操作数是小数！

---

## 4.2 关系运算符

用于比较两个值，结果只有"真（1）"或"假（0）"。

| 运算符 | 含义 | 示例 |
|:---:|:---|:---:|
| > | 大于 | 5 > 3 为真（1） |
| < | 小于 | 5 < 3 为假（0） |
| >= | 大于等于 | 5 >= 5 为真（1） |
| <= | 小于等于 | 3 <= 5 为真（1） |
| == | 等于 | 5 == 5 为真（1） |
| != | 不等于 | 5 != 3 为真（1） |

---

## 4.3 逻辑运算符

| 运算符 | 含义 | 比喻 | 示例 |
|:---:|:---|:---|:---:|
| && | 与（并且） | 两个条件都满足才通过 | (5>3) && (5<10) 为真 |
| || | 或（或者） | 只要一个条件满足就通过 | (5>3) || (5>10) 为真 |
| ! | 非（取反） | 颠倒真假 | !(5>3) 为假 |

---

## 4.4 运算符优先级口诀

> **单目 > 算术 > 关系 > 逻辑 > 赋值**

意思是：
1. 先算单目运算符（如 !、++、--）
2. 再算算术（* / % 优先于 + -）
3. 再算关系（> < >= <= == !=）
4. 再算逻辑（&& 优先于 ||）
5. 最后算赋值（=）

## 课后练习

1. 计算：5 + 3 * 2 的结果是多少？
2. 判断：(5 > 3) && (10 < 5) 的结果是真还是假？
3. 判断：!(5 == 5) || (3 != 2) 的结果是真还是假？
4. 编写程序：输入一个整数，判断它是否是偶数（提示：用 % 2）。
5. 整数除法：10 / 4 的结果是多少？10.0 / 4 呢？
