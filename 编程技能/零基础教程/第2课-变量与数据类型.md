# 第2课：变量——给数据贴标签

> **老师**：同学们好！上节课我们知道了计算机是怎么工作的，还跑了第一个程序。今天我们来学 C 语言最重要的概念——**变量**。

---

## 2.1 变量是什么？

**变量 = 一个带标签的盒子**

想象你有一个盒子：
- 盒子上贴了标签，写着"年龄"
- 你在盒子里放了一张纸，上面写着"18"
- 后来你觉得不对，把纸换成"20"
- 标签没变，但里面的内容变了

这就是变量！

```c
int age;      // 定义了一个叫 age 的盒子，用来装整数
age = 18;     // 在盒子里放 18
age = 20;     // 把盒子里的内容换成 20
```

---

## 2.2 数据类型——盒子的类型

不同的数据需要不同类型的盒子：

| 数据类型 | 关键字 | 大小 | 能装什么 | 比喻 |
|:---|:---|:---:|:---|:---|
| 整型 | int | 4字节 | 整数（-21亿 ~ 21亿） | 装整数的盒子 |
| 字符型 | char | 1字节 | 单个字符（'A', 'b', '5'） | 装字母的盒子 |
| 单精度浮点型 | float | 4字节 | 小数（3.14） | 装小数的盒子 |
| 双精度浮点型 | double | 8字节 | 更精确的小数 | 更大的小数盒子 |

**例子**：
```c
int age = 20;           // 年龄是整数
char grade = 'A';       // 成绩等级是单个字符
float price = 9.99;     // 价格是小数
double pi = 3.1415926;  // 圆周率需要更精确
```

---

## 2.3 变量命名规则（考试必考！）

给变量起名字要遵守以下规则：

1. **只能包含**：字母（a-z, A-Z）、数字（0-9）、下划线（_）
2. **不能以数字开头**：`2abc` 是错的，`abc2` 是对的
3. **区分大小写**：`age` 和 `Age` 是两个不同的变量
4. **不能使用关键字**：`int`、`float`、`return` 等系统保留字不能用

**考试常考**：以下哪个是合法的变量名？
- 合法：`_name`、`student1`、`myAge`、`count`
- 不合法：`1st`（数字开头）、`my-name`（有横线）、`int`（关键字）

---

## 2.4 赋值操作

等号 = 在 C 语言里不叫"等于"，叫"赋值"。

**赋值的含义**：把右边的值放到左边的盒子里

```c
int x;      // 定义一个整型变量 x
x = 5;      // 把 5 放入 x 的盒子
x = x + 1;  // 把 x 当前的值（5）加 1，再放回 x 的盒子（变成 6）
```

注意：x = x + 1 在数学上不成立，但在编程中是对的！意思是"把 x 加 1 后再存回 x"。

---

## 2.5 定义和初始化

**定义**：创建一个盒子
```c
int x;      // 定义了一个盒子，但里面是空的（垃圾值）
```

**初始化**：创建盒子的同时放东西进去
```c
int x = 5;  // 定义盒子，同时放入 5
```

**建议**：定义变量时一定要初始化，否则盒子里的垃圾值会让你很头疼！

---

## 2.6 完整示例

```c
#include <stdio.h>

int main() {
    // 定义并初始化变量
    int age = 20;
    float height = 1.75;
    char grade = 'A';
    
    // 输出变量的值
    printf("我的年龄是：%d\n", age);
    printf("我的身高是：%f\n", height);
    printf("我的成绩是：%c\n", grade);
    
    // 修改变量的值
    age = 21;
    printf("明年我%d岁了\n", age);
    
    return 0;
}
```

**输出结果**：
```
我的年龄是：20
我的身高是：1.750000
我的成绩是：A
明年我21岁了
```
