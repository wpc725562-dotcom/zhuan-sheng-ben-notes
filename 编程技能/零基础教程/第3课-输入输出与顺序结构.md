# 第3课：输入输出——让程序和人类对话

> **老师**：上节课我们学会了用变量存数据。但程序不能自娱自乐，它需要和用户交流——接收用户的输入，然后显示结果。今天我们就来学这个。

---

## 3.1 printf：向屏幕输出

printf 就是"打印"到屏幕的意思。

**基本用法**：
```c
printf("你要说的话");
```

**格式化输出**：用占位符来输出变量的值
```c
int age = 20;
printf("我%d岁了", age);  // %d 是整数的占位符
```

**常用占位符**：
| 占位符 | 对应类型 | 示例 |
|:---|:---|:---|
| %d | int（整数） | printf("%d", 10); |
| %f | float/double（小数） | printf("%f", 3.14); |
| %c | char（字符） | printf("%c", 'A'); |
| %s | 字符串 | printf("%s", "hello"); |

**转义字符**：
| 转义符 | 含义 |
|:---|:---|
| \n | 换行 |
| \t | 制表符（Tab） |

---

## 3.2 scanf：从键盘获取输入

scanf 从键盘读取用户输入。

**基本用法**：
```c
int age;
scanf("%d", &age);  // 注意：age 前面要加 &！
```

**重点**：一定要加 &（取地址符）！不加 & 程序会崩溃。

**完整示例**：
```c
#include <stdio.h>

int main() {
    int age;
    printf("请输入你的年龄：");
    scanf("%d", &age);
    printf("你%d岁了！\n", age);
    return 0;
}
```

## 3.3 顺序结构

程序默认是从上到下、一行一行执行的。这叫**顺序结构**。

```c
int a = 5;      // 第1步
int b = 10;     // 第2步
int c = a + b;  // 第3步
printf("%d", c); // 第4步
```

就像读一本书，按顺序读，不能跳页。
