# Profile 文案（英文，简单英语版）

> 使用方法：复制下面内容到 Upwork / Fiverr / Freelancer 的 Profile 栏。
> 中文注释是给你看的，**不要**复制进平台。

---

## 1. 标题（Title，用于 Upwork 和 Freelancer）

```
Junior JavaScript Developer | HTML, CSS, Node.js | Fast & Reliable
```

> 中文意思：初级 JavaScript 开发者 | HTML, CSS, Node.js | 快速可靠
> 写 "Junior" 是故意的——客户期望低，你容易拿到单。

## 2. 个人简介（Overview / Bio，Upwork 200 词内）

```
Hi! I am a JavaScript developer from China.

I can help you with:
- Simple websites (HTML, CSS, JavaScript)
- Small scripts and automation (Node.js)
- Fixing bugs in existing code
- Converting ideas into working web pages
- Python scripts and small tools

Why choose me:
- Fast delivery (most tasks in 1-3 days)
- Clear communication (I reply quickly)
- Affordable price for small projects
- I always test my code before delivery

I am a student, so I am learning every day. I take every job seriously.
If you need something simple and reliable, I am your person.

Let me know your idea - I will reply within a few hours.
```

> 中文：我是一个来自中国的 JavaScript 开发者。我能做：简单网站、小脚本和自动化、修 bug、把想法做成网页、Python 小工具。为什么选我：交付快、回复快、价格低、交付前测试。我是学生，每天学习。需要简单可靠的人，找我。告诉我你的想法，我几小时内回复。

## 3. Fiverr 版本（更短）

Fiverr 的 Gig 描述需要简短，Profile 用这个：

```
I am a JavaScript developer. I build simple websites, fix bugs,
and write small automation scripts with Node.js and Python.

Fast delivery. Clear communication. Fair price.
```

## 5. 时区 / 在线时间（Timezone）

- 时区：China Standard Time (GMT+8)
- 在线时间：写 "Available 8:00-23:00 Beijing time"（你学习之余都能回消息）
- Upwork 会显示时区差，海外客户白天你晚上，**当天必回**就够

## 6. 一句话简介（Fiverr / Freelancer 的 Short Intro）

```
Fast & reliable JS developer for small web tasks
```

## 7. 关于你（About You，可选，写给客户看的故事）

```
I am a computer science student in China. I started coding because
I love solving problems. I build small tools and websites for fun
and now I want to help other people with their projects.

I am honest and hardworking. If I cannot do something, I will tell
you directly - no fake promises.
```

> 中文：我是中国的计算机专业学生。我因为喜欢解决问题而开始编程。我平时做小工具和网站，现在想帮别人做项目。我诚实努力。做不到的事我会直接告诉你，不假承诺。
