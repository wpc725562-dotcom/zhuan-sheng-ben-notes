# 定价策略（新手期）

> 核心原则：**先拿好评，再涨价。** 前 3 单便宜点，拿到 2-3 个五星好评后翻倍。

---

## 一、建议报价表（美元，新手期）

| 项目类型 | 建议报价 | 交付时间 |
|---|---|---|
| 修改/修复一个小 Bug | $20 - $40 | 1-2 天 |
| 静态网站（单页 landing page） | $50 - $100 | 2-3 天 |
| 简单网页应用（表单/列表/展示） | $100 - $200 | 3-5 天 |
| Node.js 脚本/自动化小工具 | $50 - $150 | 2-4 天 |
| Python 数据处理脚本 | $40 - $120 | 2-4 天 |

> 拿到 3 个好评后，价格可以翻一倍。别担心——老客户不会因为涨价走，新客户看的是你已有好评。

---

## 二、Upwork 定价要点

1. **Connects（投标点数）很贵**：新账号每月只有 10-20 个免费 Connects，用完了要买。**只投你 80% 有把握的单**
2. 前 2 单，价格可压到 $15-$25 抢单，目标只是好评
3. 报价写**固定价**（Fixed Price），不要写按小时（Hourly），你还不熟悉效率
4. 平台抽成：**前 $500 抽 20%**（即你报 $100 实际拿 $80），报价时要考虑进去
5. 用里程碑（Milestone）：项目分 2-3 阶段收款，保护自己不白干

## 三、Fiverr 定价要点

1. Fiverr 是"卖家定价"模式：你设定 Gig 价格，客户直接买
2. 新手 Gig 定价参考：
   - `I will build a simple landing page` → $25
   - `I will fix your JavaScript bug` → $30
   - `I will write a Node.js automation script` → $50
3. Fiverr 抽成 20%（+$2 处理费，由客户付）
4. 用 `Gig Extras` 加价：加急 +$20、额外页面 +$30、多语言版本 +$15

## 四、Freelancer 定价要点

1. 竞标模式：你报出价格，客户选最低/最好的
2. 新手建议报价比同行低 20-30% 抢单
3. 抽成 10% 起（会员费 $0 开始）
4. 固定价更简单，别选按小时

---

## 五、收款换算参考（2025 年大致汇率）

- $100 ≈ ¥720 人民币
- 平台抽成 20% 后，$100 实际拿 $80 ≈ ¥580
- 提现到国内银行卡（Payoneer）有 1-2% 汇损

## 六、报价模板（发给客户确认）

```
My quote for this project: $【价格】 fixed price.
Included:
- 【功能1】
- 【功能2】
- Delivery in 【天数】 days
- 2 rounds of free revision

Not included (if I need to add, extra $【】):
- 【比如：logo design、3rd party API fees】

Does this work for you?
```

> 中文：项目报价【价格】美元固定价。包含：功能1、功能2、【天数】天交付、免费修改 2 次。不包含：logo 设计、第三方 API 费用。这样可以吗？
