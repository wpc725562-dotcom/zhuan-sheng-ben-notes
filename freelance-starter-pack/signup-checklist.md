# 注册操作清单（Step-by-Step）

> 注册必须你亲手操作（需要短信验证码、身份证上传、银行卡绑定）。
> 我做的每一步都给出中英文对照，你照着填就行。

## 第一步：注册 Payoneer（派安盈）—— 收款必备 ⭐

**为什么先注册这个：** Fiverr 和 Upwork 注册时都要填收款方式，没有 Payoneer 你没法收款。

**准备材料：**
- 身份证（正反面清晰照片，手机拍就行）
- 国内银行卡（任意银行，用于提现美元→人民币）
- 手机号（收验证码）
- 邮箱

### 操作步骤

```
1. 打开 payoneer.com
   → 右上角点「中文」切换语言
   → 点「注册」

2. 选择账户类型
   → 选「个人」→ 下一步
   → 选「自由职业者 / Freelancer」
   → 下一步

3. 填写基本信息
   姓名：填身份证上的拼音（如：WANG SI）
   邮箱：填你的常用邮箱
   国家：中国 / China
   手机号：+86 138xxxxxxxx
   密码：自己设一个

4. 填写地址（用中文拼音）
   地址：街道名（如：Wushan Road）
   城市：Guangzhou（或你的城市）
   省份：Guangdong
   邮编：510000

5. 上传身份证
   → 正反面照片
   → 系统自动识别信息，核对一下

6. 绑定银行卡
   银行名称：Bank of China / ICBC / 你的银行
   卡号：你的银行卡号
   户名：和身份证一致

7. 提交审核
   → 审核 1-3 天
   → 审核通过后，你会收到邮件
   → 登录后能看到「美国收款账户」信息（记下来，后面在 Upwork 要用）
```

**⚠️ 常见问题：**
- 审核不通过 → 检查名字拼音是否和身份证一致，检查银行卡号是否输错
- 手机收不到验证码 → 检查手机号前 +86 是否写了，等 1 分钟重试
- 目前 Payoneer 注册不需要护照，身份证即可

## 第二步：注册 Fiverr（最简单，先出第一单）

**Fiverr 是这三个平台里最容易出第一单的**——客户主动找你，不用竞标。

### 操作步骤

```
1. 打开 fiverr.com → 点 Sign Up

2. 注册方式任选：
   → 用邮箱注册（推荐）
   → 或 Google 账号登录

3. 填用户名
   → 建议：wpc725562 或类似（和你的 GitHub 一致，方便客户查）
   → 注意：用户名不能改，想好再填

4. 填 Profile
   → 头像：建议用真实头像（客户信任感）
   → 描述：复制 portfolio-guide.md 里的英文描述
   → 语言：English + Chinese（选上）

5. 创建第一个 Gig（卖服务）
   → 点右上方头像 → Selling → Create a New Gig
   → 标题：I will build a simple website or fix JavaScript bugs
   → 类别：Programming & Tech → Web Development
   → 标签：javascript, html, css, node.js, bug-fix
   → 价格：$25（基础版）

6. 设置收款
   → 点 Earnings → Add Payout Method
   → 选 Payoneer
   → 填你的 Payoneer 美国收款账户信息
```

**⚠️ 常见问题：**
- 国内访问 fiverr.com 可能慢——这是正常的，用我们的代理环境（mihomo）应该能访问
- 第一个 Gig 审核 24 小时
- 没单很正常——刚注册时客户看不到你，等 2-3 天系统开始推荐

## 第三步：注册 Upwork

**Upwork 是**单价最高**的，但 Profile 审核比较严。**

### 操作步骤

```
1. 打开 upwork.com → Sign Up → I'm a freelancer

2. 填基本信息
   → 全名：WANG SI（用拼音）
   → 邮箱：你的邮箱
   → 密码：自己设
   → 国家：China
   → 语言：English（中级或高级）

3. 填职业信息
   → 职业：Web Developer / JavaScript Developer
   → 经验：Entry Level（实话实说，你是学生）
   → 技能：选 JavaScript, HTML, CSS, Node.js, Python
   → 教育：College / University（填你的学校）
   → 时薪：$15/hour（新手价，先拿好评）

4. 写 Profile（用 profile-en.md 的内容）
   → 标题：Junior JavaScript Developer | HTML, CSS, Node.js
   → 概述：复制 profile-en.md 里的英文 Bio
   → 作品集：链接 GitHub 仓库（todo-app、url-shortener、sales-dashboard）

5. 上传头像
   → 建议用真实头像（客户信任感）

6. 设置收款
   → 选 Payoneer
   → 填你的 Payoneer 美国账户信息

7. 提交审核
   → 审核通常 24 小时 - 5 天
   → 审核通过后，你会收到邮件通知
```

**⚠️ 常见问题：**
- Profile 审核不通过 → 常见原因：头像不是真人、描述太短、技能不匹配。修改后重新提交
- 审核通过后只有 10 个 Connects（免费）→ 前 2 单只投把握大的
- 被拒也不要紧，改改再提交

## 三平台注册顺序

```
Payoneer（1-3天审核）
     ↓
Fiverr（即时注册，Gig 审核 24h）
     ↓
Upwork（Profile 审核 1-5天）
```

**建议：先注册 Payoneer，等审核的同时注册 Fiverr。**

```

  − 耗时：你写代码 3-5 天 + 平台审核 1-2 天 + 提现 1-2 天
  ≈ 一周内到手
```
