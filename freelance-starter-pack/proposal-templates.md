# Proposal 投标模板（英文）

> 使用方法：每次接单复制模板 → 把【】里的内容改成客户的具体信息 → 发送。
> Upwork 投递上限 5 个 Connects 也要投，值得的。

---

## 模板 A：网站搭建 / 网页制作（最常用）

```
Hi 【客户名字】,

I read your project about 【项目主题，比如 building a landing page for your coffee shop】.

I am a JavaScript developer, and I can build this for you:
- Clean and modern design
- Works on phone and computer (responsive)
- Fast loading
- Easy to update later

I can finish it in 【3-5】 days.

Here is my offer: 【$80】 for the whole project.

Do you have a design in mind, or should I suggest one? I can show
you a sample first before we start.

Thanks for your time!
【你的名字】
```

> 中文：你好【客户】，我看了你的项目【主题】。我是 JS 开发者，能做：干净现代的设计、手机电脑都能用、加载快、以后好改。【3-5】天完成，报价【80】美元。你有设计想法吗，还是我来建议？开工前我可以先给你看个样例。谢谢！

---

## 模板 B：修复 Bug / 修改现有代码

```
Hi 【客户名字】,

I can help you fix this 【bug/问题描述】.

This looks like a 【推测的原因，比如 CSS conflict or a JavaScript error】 problem.
I have fixed this type of issue before.

What I will do:
1. Look at your code and find the problem
2. Fix it carefully
3. Test everything so nothing else breaks

My price: 【$30】, fixed price.
I can start today and deliver in 【2】 days.

Can you share the file or link? I will check it right away.

Best,
【你的名字】
```

> 中文：我能帮你修这个问题【bug】。这看起来像【原因】。我会：看代码找问题、仔细修、测试别的地方不坏。价格【30】美元，固定价。今天开工，2 天交付。能把文件或链接发我吗？我马上看。

---

## 模板 C：写小工具 / 脚本（自动化、数据处理）

```
Hi 【客户名字】,

I can write this 【script/小工具描述】 for you with Node.js/Python.

My plan:
- 【步骤1，比如 collect data from your website】
- 【步骤2，比如 save it to Excel/CSV】
- 【步骤3，比如 run it automatically every day】

You will get:
- Working code + simple instructions (with screenshots)
- I test it on real data before delivery

Price: 【$50】 fixed.
Time: 【4】 days.

If you want, I can do a free small test first so you can see my work.

Thanks!
【你的名字】
```

> 中文：我可以用 Node.js/Python 写这个脚本【描述】。计划：收集数据、存到 Excel、每天自动跑。你得到：能跑的代码+带截图的使用说明，交付前我用真实数据测试。价格【50】美元，4 天。如果你愿意，我可以先免费做个小测试让你看看我的水平。谢谢！

---

## ✍️ 填模板的 5 个技巧

1. **每句话都要提到客户的项目**（不要只发通用模板）——第一句必须引用客户的话
2. **报价给区间下限**（新手期）：写固定价，不要写"价格可谈"
3. **主动给下一步**：结尾一定要问问题（"你有设计吗？""能把文件发我吗？"）
4. **简短**：Upwork 客户 30 秒扫一眼，别超过 8 行正文
5. **不说自己"新手"**：说"student"（学生）可以，别说 "beginner"（新手）、"no experience"

## 🚫 绝对不要写

```
I have no experience but I am a quick learner.  ← 客户直接跳过
I can do everything.                            ← 不真实
My price is very low compared to others.        ← 显得没底气
Please give me this job.                        ← 太卑微
```
