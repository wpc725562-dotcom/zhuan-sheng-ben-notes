# 平台注册 + 收款指南

> 重要顺序：**先注册 Payoneer 收款 → 再注册平台**，因为平台要求填收款方式。

---

## 第一步：注册 Payoneer（派安盈）——收款必备

**为什么必须用：** 海外平台的钱到不了支付宝/微信，Payoneer 是中国人收美元最便宜的方式。

| 项目 | 说明 |
|---|---|
| 官网 | payoneer.com（有中文界面） |
| 费用 | 注册免费，无年费 |
| 需要 | 身份证、国内银行卡（提现用） |
| 注册时间 | 10-15 分钟 |
| 审核 | 1-3 天 |
| 提现 | 美元 → 人民币，直接到国内银行卡 |

**注册步骤：**
1. 打开 payoneer.com → 选中文 → 点"注册"
2. 选"我是自由职业者/个人" → 填邮箱、手机号
3. 上传身份证正反面照片
4. 绑定你的国内银行卡（用于提现）
5. 等 1-3 天审核通过
6. 审核通过后你会得到**一个美国的收款账号**（用于 Upwork 收款）

## 第二步：注册 Upwork

| 项目 | 说明 |
|---|---|
| 官网 | upwork.com |
| 注册 | 免费，用邮箱注册 |
| 审核 | Profile 审核 24 小时 - 5 天 |
| 是否需实名 | 注册不需要，收款时需要（填 Payoneer 信息） |

**注册流程：**
1. upwork.com → Sign Up → 选 "I'm looking for work"
2. 填职业：Software Developer / Web Developer
3. 填 Profile（用 `profile-en.md` 的文案）
4. 填 Payoneer 收款信息（或 PayPal）
5. 等审核通过 → 开始投标

**注意：** Upwork 新账号**每月只有 10 个 Connects**（免费），用完要花钱买。新账号要完成"Rising Talent"或前几单才能正常使用。

## 第三步：注册 Fiverr（最简单）

| 项目 | 说明 |
|---|---|
| 官网 | fiverr.com |
| 注册 | 免费，邮箱即可 |
| 审核 | 无审核，注册完就能发 Gig |
| 收款 | Payoneer / PayPal |

**注册流程：**
1. fiverr.com → Sign Up → 填邮箱+密码
2. 完成 Profile（头像、简介）
3. 点 Sell on Fiverr → Create New Gig
4. 按 `profile-en.md` 的 Fiverr 版本填 Gig
5. 设置收款（Payoneer 或 PayPal）

**Fiverr 是新手最容易出第一单的**：因为客户主动找你，不用竞标。

## 第四步：注册 Freelancer

| 项目 | 说明 |
|---|---|
| 官网 | freelancer.com |
| 注册 | 免费 |
| 收款 | Payoneer / PayPal |

**注册流程：**
1. freelancer.com → Sign Up
2. 填 Profile（复制 `profile-en.md`）
3. 设置收款 → 加 Payoneer

## 收款方式对比

| 方式 | 注册难度 | 提现到国内 | 费率 | 建议 |
|---|---|---|---|---|
| **Payoneer** | 需身份证 | 人民币/美元 | 1-2% | ⭐ 首选 |
| **PayPal** | 简单 | 人民币（绑定银联卡） | 3-5% | 备用 |
| **Wise** | 需身份 | 需中转 | 0.5-1% | 可选 |

## ⚠️ 防骗清单（必读）

1. ❌ **任何"先付费才能开工"的客户** → 骗子
2. ❌ **要求你"交保证金"的** → 骗子
3. ❌ **发链接让你"点进去确认"的** → 钓鱼
4. ❌ **声称"平台外付款，便宜点"** → 一定走平台，否则你拿不到钱
5. ✅ 永远在**平台内**沟通、收款、确认
6. ✅ 收到钱之前，不给完整代码/不提供源代码文件
