# ❌ 错题本

> 错题是**最宝贵的复习资料**！每道错题都代表一个知识漏洞。
> 使用方法：做错一道题，就记录一道。考前只看错题本！

> 🔬 **自动统计**：填完错题后运行 `node scripts/mistake-stats.mjs`，
> 自动统计薄弱知识点和错误原因分布（也支持 `--file` 指定其他错题文件、`--json` 输出）。

## 💻 计算机错题本

### 错题 #C001

- **日期**：2026-09-09
- **题目来源**：AI 教练第三课·赋值连续运算（人肉编译）
- **题目**：逐行写出 `a` 的最终值
  ```c
  int a = 3;
  a = a + 2;
  a = a * 2;
  printf("%d\n", a);
  ```
- **我的错误答案**：`6`
- **正确答案**：`10`（第一行后 a=5，第三行用的是**新的 5**，不是最初的 3）
- **错误原因**：☑ 概念不清 —— 忘了 `=` 是"往盒子里塞"，上一行已经把 `a` 覆盖掉，还在用开头的旧值
- **知识点**：变量的覆盖性赋值；`=` 从右往左读；连续赋值必须逐行更新盒子里的值
- **⚠️ 元认知警报**：**同一晚**「填表格版」的 `1+2=3 → 3+3=6 → 6+4=10` 我做对了，但**撤掉表格自己独立做**这题就错。这叫"有脚手架会、没脚手架错"＝**假掌握**，不能算过关。
- **复习记录**：
  - 第1次复习：**2026-09-10 ✅ 答 10**（合上讲义、无表格独立做对 → 假掌握警报**解除**）
  - 同型连对：第2次 ✅ `x=10; x=x-4; x=x+1; x=x*2;` 答 **14**（10→6→7→14，三行连续赋值全对）
  - **判定：「赋值覆盖 / `=` 从右往左」这一格正式过关**（连对 2 次，符合看板判据）
  - 第3次复习：待 09-12 前抽查（防遗忘）
- **配套讲义**：[1.3a 变量与赋值·零基础](/posts/computer/notes/1.3a-变量与赋值-零基础)

### 错题 #C002

- **日期**：2026-09-10
- **题目来源**：AI 教练·人肉编译（`for (i=1; i<=3; i++) s = s + i;`）
- **题目**：`int i, s = 0;` 然后 `for (i = 1; i <= 3; i++) { s = s + i; }`，`printf` 打印几？
- **我的错误答案**：`10` ← 而且**没画表格**
- **正确答案**：`6`（`s = 0+1 = 1` → `1+2 = 3` → `3+3 = 6`，循环只跑 **3 轮**）
- **错误原因**：☑ 思路不对 —— 不是算错，是**根本没算**。上一题 `i<=4` 的答案正好是 10，这次把 **10 直接搬过来了**（背邻居题的答案，人肉编译最危险的假象）
- **知识点**：`i<=3` 和 `i<=4` 是**两道不同的题**；`1+2+3 = 6`，`1+2+3+4 = 10`，少一轮差 4
- **🔑 教训（决定考场能不能拿分）**：**答案不能从上一题借**。判据不是"答对"，而是"**画出表格 + 答对**"；只给数字不给过程的，一律按错题重做
- **复习记录**：
  - 第1次复习：____-__-__  ✅/❌ ←（下次开课重做，**必须交表格**）
  - 第2次复习：____-__-__  ✅/❌
  - 第3次复习：____-__-__  ✅/❌
- **配套讲义**：[1.3a 变量与赋值·零基础](/posts/computer/notes/1.3a-变量与赋值-零基础) 第四节

## 💡 错题本使用原则

### 什么时候记错题？
1. **做错的题** — 必须记
2. **蒙对的题** — 也记，说明你还没完全掌握
3. **不会做但看了答案会的题** — 记！这是进步空间
4. **经典好题** — 即使做对了也可以记下来

### 怎么复习错题？
1. **第1次复习**：当天晚上，重做一遍
2. **第2次复习**：3天后，再重做一遍
3. **第3次复习**：1周后，再做一遍
4. 连续3次做对 → 标记为「已掌握」

### 考前冲刺看什么？
> **只看错题本！** 把错题本从头到尾过一遍，确保每道题都会做。
