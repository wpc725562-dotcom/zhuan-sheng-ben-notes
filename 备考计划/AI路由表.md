## 🧬 三层结构（本库的物理形态）

```
第1层 原始资料层  资料/英语专项(源PDF)、桌面/广东专升本资料/、历年真题/
第2层 整理页层    docs/posts/**(笔记)、资料/*.md(专项训练)、资料/英语专项/*.md(本次)
第3层 规则层      本文件 + 看板更新协议 + study-coach SKILL 协议段(pinned memory)
```

**闭环**：资料进入 → AI 提炼成卡/页 → 路由表登记 → AI 执行时查表调用 → 结果写回 → 表更新。
**用户只管扔材料**（如"这个 PDF 放桌面了"），AI 负责提取、入库、登记路由。

## 📐 新材料入库协议（AI 执行）

1. 源文件放 `资料/<科目>专项/`，用脚本转 md（禁手抄，图片页如实标注不粉饰）
2. 产物页头部写明：来源文件、完成度（如 88/100 篇全对齐）、已知缺口
3. **回本文件路由表加一行**（哪类活→查哪页）
4. 若影响学习计划，同步 [[学习进度看板]]
