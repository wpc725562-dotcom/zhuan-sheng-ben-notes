# Anki FSRS 开关：怎么开、有什么用、代价是什么

> 生成时间：2026-09-10 凌晨 · 依据：本机 `collection.anki2` 实查 + GitHub 调研
> **这份文档不改任何设置**，只是把判断材料摊开。开关由你本人在 Anki 界面里点。

---

## 一、实查结论（不是猜测）

从本机 Anki 数据库副本读出来的三件事：

| 查什么 | 查到什么 | 说明 |
|:---|:---|:---|
| 调度器版本 | `schedVer = 2`、`sched2021 = true` | 新版 V3 调度器，**FSRS 已内置** |
| 全局配置键 | 存在 `fsrsHealthCheck = true` | 这个键只有支持 FSRS 的版本才会写 |
| 是否**已在用** FSRS | **没有。2271 张卡里 0 张带 FSRS 记忆状态**（`cards.data` 全是 `{}`，没有 FSRS 必写的 `s` 稳定度字段） | 现在跑的是 **SM-2**，1987 年的老算法 |

**一句话**：你这版 Anki 白送了一个更好的算法，但默认关着，你一直在用老的那个。

---

## 二、SM-2 和 FSRS 到底差在哪（大白话）

**SM-2 的做法**：每张卡记一个「间隔倍数」（默认 250%）。答对 → 下次间隔 = 上次间隔 × 倍数；答错 → 倍数往下调。它**只看你答对答错，不知道你为什么记住**。

后果就是你在英语牌组上看到的现象：

- 2230 张里 **1341 张从未开课**（占 60%）—— 老算法排期保守，队列滚雪球，越堆越多，最后干脆不动了
- 已开课的卡间隔一涨就是几十天，但**它不知道该在几天前提醒你**，于是要么白复习（还很熟就来了），要么忘了才来（09-09 正确率只有 30%，就是这个）

**FSRS 的做法**：给每张卡建一个你的**个人遗忘曲线**（两个数：稳定度 S、可提取性 R），用你全部历史复习记录去拟合。它直接回答「这张卡此刻你还记得的概率是多少」，然后把下次复习安排在**刚好快要忘的那一刻**。

**省在哪**：同一个目标正确率下，间隔排得更准 → 重复复习次数更少。社区和 Anki 官方迁移向导的实测普遍是**复习量降 20-30%**。对你的意义是：**每天 15 分钟能覆盖更多张卡，一轮 2230 词才可能走完**（现在 40% 一轮走不完，正是因为队列卡死）。

## 三、开关在哪（Anki 23.10 及以后）

1. 打开 Anki → 主界面左侧**牌组列表**
2. 找到 `专升本英语-高频词` → 点它右边的 **⚙ 齿轮** → **显示设置**（英文界面是 `Show preferences`）
3. 滚到最下面 → 展开 **高级**（`Advanced`）
4. 勾上 **「使用 FSRS 调度器」**（`Use FSRS scheduler`）
5. 上面会多出一个 **「期望保留率」**（`Desired retention`）：**保持默认 0.9，不要动**
6. 点保存 / 返回

**给哪些牌组开**：三个都建议开 —— 英语高频词、`专升本::C语言`、`专升本::高数`。牌组设置是**各自独立**的，要一个个牌组的齿轮去点。（`错题` 两个牌组卡太少，开不开无感。）

**Anki 可能会弹窗**：说"检测到旧复习记录，是否用它们来训练模型" → **选是**。你有 2663 条历史，正好够它学你的记忆规律。如果它说"从 X 日期之前的记录忽略"，接受默认即可。

## 四、代价与风险（说清楚，不粉饰）

| 风险 | 真实情况 | 怎么应对 |
|:---|:---|:---|
| 会不会丢进度 | **不会改任何卡片内容、不会删复习记录**，只改"下次什么时候出现" | 心里有底：Anki 界面右上角**文件 → 备份**会留每日快照；改完觉得不对，同一处**取消勾选**即可退回 SM-2（老间隔会重新算，但记录不丢） |
| 头几天可能变忙 | 已开课的卡间隔会被重新计算，**短期内到期数可能突然变多**（老算法排得过松的卡会被拉回来） | 英语是**保鲜轨**，本来就"维持即可"。变多就分批清，别硬赶 |
| 期望保留率设太高 | 0.95 会让复习量大增，等于白开 | **就用 0.9**，别调 |
| 新卡（1341 张从未开课）会不会一起涌进来 | 由**每日新卡上限**控制，跟 FSRS 无关 | 那个上限**不要为了赶进度去调高**。60% 没开课不是罪，考纲要的词汇量优先，剩下的随缘 |
| 会不会反而更差 | 若你的历史数据太少/太乱，模型拟合不准，初期可能不如 SM-2 | 观察 1 周。判断标准只有一个：**同一天里，是"记得住才来"还是"早就忘了才来"**。你现在 30% 的正确率就是最坏的对照基准 |

## 五、这个结论是怎么来的（借鉴来源）

在 GitHub 上调研「复习 / 已学知识看板」的同类做法，找到 `open-spaced-repetition` 这个组织（**FSRS 官方实现，`fsrs4anki` 4061★**，Anki 内置的 FSRS 就是采纳了它的算法），以及 `nagisanzenin/engram`（1409★，2026-07 新建）。

**engram 这个项目值得单说**，因为它的核心主张和我们这两天踩的坑一模一样：

- 「**free-recall verification with receipts**」= 自由回忆 + 留证据。对治的正是你 ③ 题「只给数字不给过程」——它的判据也是**没过程不算会**
- 「**a tutor that makes you produce answers *before* it explains**」= 先答再讲，跟我们「提取练习优先」同一条
- 「**blind examiner**」= 判卷的不看讲解、只看你的作答，防"看着答案觉得会对"
- 用 **FSRS-4.5** 做记忆调度 —— 这是它把上面几条串起来的引擎

也就是说：**我们手工搭的那套（教练→先答→判过程→错题→看板），开源界已经有一个成熟实现，且它的算法引擎正是 Anki 白送但没开的那个。** 这构成"该开 FSRS"的独立佐证。

> ⚠️ engram 是 Python 写的、要 `python3`。本机只有 `python`（`python3` 不可用），且它是把 AI 当"盲考裁判"的插件形态 —— **不建议装**，我们的闭环已经按自己的方式跑通了，缺的只是调度算法。真要看思路，读它的 README 就够，不必引入运行时。

## 六、开完之后怎么验证真的生效了

改完第二天，我再从数据库副本查一次：**`cards.data` 里开始出现 `"s":` 字段的卡片数量应该 > 0**。这是 FSRS 生效的唯一硬证据，不接受"我点了"作为凭据。

同时盯这两个数（门户「🪞 复盘」「Anki」两页会显示）：

- **正确率**：目标从 30% 回到 **80% 以上**。掉下 50% 就停手（已立规矩）
- **每日到期数**：目标是从"永远清不完的 142+"变成**每天 15 分钟能做完**
