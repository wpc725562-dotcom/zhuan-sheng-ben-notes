# 📱💻 多端同步指南（电脑 + 手机 · 免费方案）

> 目标：**Obsidian 库（专升本笔记）在电脑和手机之间同步**，随时能看笔记、练题、记错题。
> 方案：**Git + GitHub**（你的仓库已托管在 GitHub，用它当同步中枢，免费）。

---

## 一、同步原理

```
电脑 Obsidian 库  ←──git push──→  GitHub 仓库  ←──git pull──→  手机 Obsidian 库
   (你的笔记本)                        (同步中枢)                 (手机 Obsidian)
```

- **GitHub 仓库** = 中间人，存所有笔记的最新版
- **电脑**：改完笔记 → push 到 GitHub
- **手机**：打开前 pull 一下 → 拿到最新笔记
- 反向也一样：手机记了错题 → push → 电脑 pull 就能看到

---

## 二、电脑端配置（Obsidian Git 插件 · 自动同步）

### 1. 安装插件
1. Obsidian 打开你的专升本库
2. 设置 → 第三方插件 → 关闭安全模式
3. 浏览社区插件 → 搜索 **"Obsidian Git"**（作者 Vinzent）→ 安装并启用

### 2. 配置自动同步（推荐）
Obsidian Git 插件设置里：
- **自动备份间隔**：开启，设 10 分钟（自动 commit + push）
- **拉取间隔**：开启，设 10 分钟（自动 pull 最新）
- 这样你**不用手动操作**，改完笔记自动同步

> ⚠️ 需要 Git 能免密访问 GitHub（你电脑已配置好 credential manager，直接能用）

### 3. 手动同步命令（不想自动时）
- 命令面板（Ctrl+P）→ 输入 `Obsidian Git: Push`（推送）
- 输入 `Obsidian Git: Pull`（拉取）

---

## 三、手机端配置（Obsidian 移动版 + Git）

### 1. 安装 Obsidian（手机）
- iOS App Store / Android 应用市场 搜索 **Obsidian** 安装

### 2. 准备 Git 访问（手机）
手机 Git 需要认证。推荐 **Fine Git**（Android 免费）或 iOS 的 **Working Copy**（需购买）：
- 连接你的 GitHub 账号（用 token 认证，见下方）

### 3. 克隆仓库到手机
1. 手机 Obsidian 打开 → 选择「从 Git 克隆 / Open from Git」（新版支持）
2. 填仓库地址：`https://github.com/wpc725562-dotcom/zhuan-sheng-ben-notes.git`
3. 输入认证（GitHub token）
4. 克隆完成后就是你的全部笔记

### 4. 手机同步
- 每次打开 Obsidian 前：Pull 拉最新
- 手机改完（记错题/打卡）：Push 推上去

---

## 四、GitHub Token 获取（手机认证用）

1. 电脑浏览器打开 GitHub → 右上角头像 → Settings
2. 底部 **Developer settings** → **Personal access tokens** → Tokens (classic)
3. Generate new token → 勾选 `repo` 权限 → 生成
4. 复制 token（只显示一次），手机 Git 工具用它认证

> ⚠️ **Token 相当于密码**，别写进笔记/仓库，只放手机 Git 工具里。

## 五、推荐工作流（每天）

| 时机 | 动作 |
|:---|:---|
| 电脑学习时 | 直接在 Obsidian 改笔记/练题（自动 push） |
| 睡前 | 电脑 Obsidian 确认已同步（`Obsidian Git: Push`） |
| 白天出门 | 手机打开 Obsidian → Pull → 用「学习主页」看进度/刷题 |
| 手机记了错题 | 手机 Push → 回家电脑 Pull 就能看到 |

---

## 六、常见问题

| 问题 | 解决 |
|:---|:---|
| 手机克隆显示需要认证 | 用 GitHub Token（见第四节） |
| 同步冲突 | 少用「同时在不同设备改同一文件」；冲突时 Obsidian Git 会提示 |
| 大文件不同步 | 仓库已 gitignore 掉大文件（ForestDeer 副本等），只同步 md 笔记 ✅ |
| 手机 Obsidian 没 Git 选项 | 装最新版 Obsidian，或装 Obsidian Git 移动版插件 |
