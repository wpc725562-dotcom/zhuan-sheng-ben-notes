## 二、提示词（复制这段给外部模型）

```
你是广东专升本备考资料审计专家。我提供一个知识库的【实际文件内容】，
请你按"能否直接帮我考上公办本科"的实战标准评估缺陷。

铁律（违反即视为回答无效）：
1. 只依据我给你的文件内容下结论。禁止根据目录名、文件名、常识模板推测
   "通常缺什么"。
2. 每指出一个缺口，必须同时给出：
   (a) 你依据的具体文件名；
   (b) 该文件里证明它缺失的原文片段或行数；
   (c) 你判断它"缺失"而非"已存在"的理由。
3. 判断"有内容"的标准是【实质正文量】，不是文件是否存在。
   一个 0.6KB、自标"同型演练/占位"的文件，不等于该年份真题已具备。
   请区分三档：A=原卷级完整真题；B=回忆版/公开整理（题量完整）；
   C=占位页（仅结构或考点清单，无题）。
4. 区分【广东专升本】与【考研】的科目差异。政治科目尤其注意：
   广东专升本考纲历来是"毛中特+习思想+时政"，不要套用考研的
   "思修/法律/马原"科目表来判定我缺什么。若你不确定，标注为
   "需以官方大纲核实"，不要断言。
5. 不要建议我重复导入仓库里已有的资料。给建议前先在我提供的内容里
   搜索是否已存在同类。
6. 输出分三部分：
   ① 证据充分的真实缺口（按提分性价比排序，标注 A/B/C 档）
   ② 我无法从现有内容判断、需要我补充材料才能评估的项
   ③ 你认为我可能高估或低估的风险
   每条不超过 3 行。禁止使用"致命伤""严重断层"等无量化修辞。

我的背景：2027 届广东普通专升本，四科满分 政治100/英语100/高数100/计算机200。
以下是我的文件内容：
【在此粘贴文件】
```

## 四、上一份诊断的核查结论（避免重复采信）

曾有模型基于"32 个文件清单"（实际 1168 个）给出 5 条断言，逐条实测：

| 断言 | 实测 |
|:---|:---|
| 高数真题 2020–2026 彻底空白 | 错。2018–2024+2026 共 8 个年份文件 |
| 政治缺毛概 | 错。`02-毛泽东思想.md` 等 5 篇 + Mayi 毛概习题答案 |
| 英语缺 2013–2024 共 12 年 | 错。2005–2026 连续覆盖，2013–2019 每年 100+ 题 |
| 计算机缺 2024–2026 与数据结构 | 错。2018–2026 九年文件；数据结构 2.1–2.9 九篇完整 |
| 大纲还是 2024 版 PDF | 前提虚构，仓库无此文件 |

**但它的结论并非全无价值**：真实缺口确实存在，只是位置和它说的不同——
是**部分年份只有 C 档占位页**（政治 2018–2022、计算机 2018–2020），
以及**高数 2025 断档**、**时政库仅 50 行**。
