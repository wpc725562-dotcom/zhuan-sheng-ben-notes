## 一、问题诊断（修正版）

### 用户的核心诉求

| 之前方案（错误理解） | 用户实际要的 |
|:---|:---|
| 搜"专升本 C语言 指针"大词混杂 | **按机构搜**：精通学堂、杰哥专升本、Mayi政治、空卡、欢姐、孟涛、张成叔……各机构的内容分别搜出来 |
| 播放量 > 1000 规则过滤 | **AI 自行优化**：由 AI 判断哪些内容质量高、讲得对、适合零基础 |
| 搜一次完事 | 自动化 + 考点图谱 + 漂亮展示 |
| 只做高频 TOP20 | **考纲全部考点 + 高频考点** |

### 什么是"机构"？

在专升本领域，内容产出方主要是**培训机构/知名UP主**，每个机构有自己的风格和优势科目：

| 机构/UP主 | 强项科目 | 风格 |
|:---|:---|:---|
| **杰哥专升本** | 高数 | 真题讲解，针对性强 |
| **宋浩老师** | 高数 | 零基础细致讲解 |
| **精通学堂** | 高数 | 系统课 |
| **欢姐专升本** | 政治 | 广东专门 |
| **Mayi政治** | 政治 | 带背/磨耳朵 |
| **空卡空卡空空卡** | 政治 | 口诀速成 |
| **孟涛老师** | 计算机 | 广东真题解析 |
| **鹏哥C语言** | C语言 | 零基础入门 |
| **张成叔** | C语言 | 题库/考点 |
| **刘晓艳** | 英语 | 语法/单词 |
| **我是瑞斯拜** | 英语 | 作文模板 |

**融合优化**：同一考点，把各机构讲的都找出来 → AI 对比 → 标注"哪家讲得最好/最适合你/何时看" → 组合成最优学习路径（比如：概念看宋浩 → 真题看杰哥 → 冲刺看猴博士）。

## 二、升级方案（v2）

### 维度 1：机构维度搜索 + AI 融合（核心修正）

```
之前（v1）：按考点关键词搜索 → 结果混杂
现在（v2）：按 [机构 × 考点] 双维度搜索 → 每个考点收集"各家说法" → AI 融合优化
```

**搜索矩阵：**

```
        考点1   考点2   考点3   ... 考点N
机构A   [搜]    [搜]    [搜]        [搜]
机构B   [搜]    [搜]    [搜]        [搜]
机构C   [搜]    [搜]    [搜]        [搜]
...
```

**AI 融合优化规则（我来执行）：**

| 判断维度 | 说明 |
|:---|:---|
| 内容质量 | 看标题/简介/评论，判断是否真讲这个考点、讲得是否清楚 |
| 适配度 | 零基础 vs 有基础 vs 冲刺，标注适合阶段 |
| 机构特色 | 记录"这家机构这套课强在哪" |
| 去重 | 同一机构同一考点多视频只留最优 |
| 广告/付费 | AI 识别并剔除（B站课程"cheese"标记） |

### 维度 2：考点→资源双映射（保留）

```
考点（考纲全部 + 高频标注）
  ├── 📺 视频（按机构分组，AI 标注推荐度/适合阶段/时长/章节锚点）
  ├── 📖 笔记（仓库章节页）
  ├── 📝 真题（年份/题号）
  └── 🛠️ 练习（刷题链接）
```

### 维度 3：自动化流水线（保留，适配机构维度）

```
考点清单 + 机构清单
   → 生成搜索任务矩阵（考点 × 机构）
   → playwright 批量精准搜索
   → AI 融合优化（去重/评分/标注）
   → 输出考点资源图谱（Markdown）
   → 一键更新
```

### 维度 4：UI 升级（保留）

VitePress "考点资源卡片"：考点 → 各机构方案对比 → 最优路径推荐。
