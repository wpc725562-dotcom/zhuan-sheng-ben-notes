### 四、简答题

**36.** `p` 是指针变量，存地址；`*p` 是 p 指向的值；`&a` 是 a 的地址。`(*p)++` 先解引用再自增 → 改指向的值；`*p++` 等价于 `*(p++)` → 先取旧值，指针后移。

**37.** 栈：后进先出 LIFO，只在栈顶操作。应用：括号匹配、函数调用递归。队列：先进先出 FIFO，队头出队队尾入队。应用：BFS、缓冲区。

**38.** struct：各成员独立存储，sizeof = 各成员之和（含对齐）；union：所有成员共享同一块内存，sizeof = 最大成员。`sizeof(S)=8`，`sizeof(U)=4`。

**39.** 快速排序：选基准，小的放左大的放右，基准归位，递归左右。第一趟结果：`[27, 38, 13] 49 [76, 97, 65]`。

### 六、应用题

**43.**
```c
#include <stdio.h>
int main() {
    int n, i, flag = 1;
    scanf("%d", &n);
    if (n < 2) flag = 0;
    for (i = 2; i * i <= n; i++)
        if (n % i == 0) { flag = 0; break; }
    if (flag) printf("是素数\n");
    else printf("不是素数\n");
    return 0;
}
```

**44.**
```c
#include <stdio.h>
int main() {
    int a[20], i, count = 0, sum = 0;
    for (i = 0; i < 20; i++) scanf("%d", &a[i]);
    for (i = 0; i < 20; i++)
        if (a[i] % 5 == 0) { count++; sum += a[i]; }
    printf("个数=%d, 和=%d\n", count, sum);
    return 0;
}
```

**45.**
```c
#include <stdio.h>
#include <string.h>
struct Student {
    int id; char name[20]; float score;
};
int main() {
    struct Student stu[3], *max;
    int i;
    for (i = 0; i < 3; i++)
        scanf("%d%s%f", &stu[i].id, stu[i].name, &stu[i].score);
    max = &stu[0];
    for (i = 1; i < 3; i++)
        if (stu[i].score > max->score) max = &stu[i];
    printf("最高分: %d %s %.1f\n", max->id, max->name, max->score);
    return 0;
}
```
