**完整解答（照着抄一遍，然后合上默写）**：

- **树的路径长度**：从树根到每个结点的路径长度（经过的边数）之和。对于一棵二叉树，路径长度 = 每个结点所在层数减1之和。
- **树的带权路径长度（WPL, Weighted Path Length）**：树中所有叶子结点的带权路径长度之和。每个叶子结点的带权路径长度 = 该结点的权值 × 该结点到根结点的路径长度。

**公式**：WPL = ∑(wᵢ × lᵢ)，其中 wᵢ 为第 i 个叶子结点的权值，lᵢ 为其路径长度。

**完整解答（照着抄一遍，然后合上默写）**：

`printf` 不用 `&`，它只是**读**值来显示，不需要写回去。

### 10. 【高等数学】【连续性·参数确定】 ★ 基础

设函数 $f(x) = \begin{cases} e^{2x}, & x < 0 \\ a + x, & x \ge 0 \end{cases}$ 在 $x = 0$ 处连续，求常数 $a$ 的值。

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

连续性条件：$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^+} f(x) = f(0)$。

左极限：
$$
\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} e^{2x} = e^{0} = 1
$$

右极限与函数值：
$$
\lim_{x \to 0^+} f(x) = f(0) = a + 0 = a
$$

由连续性得 $a = 1$。

**这题在考什么**：

分段函数连续性的判断，左极限 = 右极限 = 函数值


</details>

### 14. 【高等数学】【不定积分·直接积分法】 ★ 基础

求不定积分 $$\int \left(\frac{1}{x} + \cos x - e^x\right) \, dx$$

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

$$
\begin{aligned}
\int \left(\frac{1}{x} + \cos x - e^x\right) \, dx
&= \int \frac{1}{x} \, dx + \int \cos x \, dx - \int e^x \, dx \\
&= \ln |x| + \sin x - e^x + C
\end{aligned}
$$

**这题在考什么**：

基本积分公式 $\int \frac{1}{x} dx = \ln |x| + C$，$\int \cos x \, dx = \sin x + C$，$\int e^x \, dx = e^x + C$


</details>

### 15. 【C语言】【编程题】 ★★ 中档

10 个成绩，求平均分并统计高于平均分的人数

数据：`{90,85,76,65,54,88,92,73,81,70}`

```c
int main() {
    int a[10] = {90,85,76,65,54,88,92,73,81,70};
    int i, count = 0;
    double sum = 0, avg;
    for (i = 0; i < 10; i++) sum += a[i];
    avg = sum / 10;                    /* 77.4 */
    for (i = 0; i < 10; i++)
        if (a[i] > avg) count++;
    printf("平均分=%.1f 高于平均分%d人\n", avg, count);
    return 0;
}
```

**答案**：总和 774，平均分 **77.4**，高于平均分 **5 人**（90、85、88、92、81）。

**解析**：

`sum/10` 若 sum 声明为 int 会做整除得 77——平均分要保留小数必须用 `double` 或 `1.0*sum/10`。
