### 四、简答题

**36.** DFS：深度优先，用栈（递归），应用：判断连通性、查找路径。BFS：广度优先，用队列，应用：最短路径、网络爬虫。

**37.** Prim：加点法，从顶点出发每次选最短跨边，O(n²)，适合稠密图。Kruskal：加边法，所有边按权值排序，每次选最短且不成环，O(e log e)，适合稀疏图。

**38.** 先序：根左右 → A B D E C<br>中序：左根右 → D B E A C<br>后序：左右根 → D E B C A

**39.** 递归：函数调用自身，代码简洁但有栈开销和重复计算。迭代：循环实现，效率高但代码较长。斐波那契递归缺陷：重复计算指数爆炸（fib(4) 需算 fib(3) 和 fib(2)，fib(3) 又需算 fib(2) 和 fib(1)）。迭代版：

```c
int fib_iter(int n) {
    if (n <= 2) return 1;
    int a = 1, b = 1, c, i;
    for (i = 3; i <= n; i++) {
        c = a + b;
        a = b; b = c;
    }
    return c;
}
```

#include <stdio.h>
int main() {
    int n, a = 1, b = 1, c, i;

    *b = t;
