**完整解答（照着抄一遍，然后合上默写）**：

利用第二个重要极限 $\lim_{u \to \infty} \left(1 + \frac{1}{u}\right)^u = e$，令 $u = \frac{x}{2}$，则 $x = 2u$，当 $x \to \infty$ 时 $u \to \infty$：

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 重复地遍历待排序序列，依次比较相邻两个元素，如果顺序错误则交换它们。
- 每一轮遍历将最大（或最小）的元素"冒泡"到序列的末尾。
- 共进行 n-1 轮，每轮比较次数递减。

**时间复杂度**：
- 平均情况：O(n²)
- 最坏情况（逆序）：O(n²)
- 最好情况（已有序，优化后）：O(n)
- 空间复杂度：O(1)
- 稳定性：稳定

### 13. 【高等数学】【极限·抓大头法则】 ★ 基础

求极限 $$\lim_{x \to \infty} \frac{2x^2 + 3x + 1}{x^3 + 5x^2 - 2}$$

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

分子最高次项为 $x^2$，分母最高次项为 $x^3$，分母次数更高，极限为 $0$：

$$
\lim_{x \to \infty} \frac{2x^2 + 3x + 1}{x^3 + 5x^2 - 2}
= \lim_{x \to \infty} \frac{2x^2}{x^3}
= \lim_{x \to \infty} \frac{2}{x}
= 0
$$

**这题在考什么**：

抓大头法则（分子次数 < 分母次数 ⟹ 极限为 $0$）


</details>

### 14. 【高等数学】 ★ 基础

「抓大头法则」是什么？什么时候能用？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

用于 `∞/∞` 型极限：**分子分母都只保留次数最高的那一项，其余全扔掉**。

例：`(3x³ + 2x² - 1)/(5x³ - 4x + 7)`，x→∞ 时抓大头 → `3x³/5x³ = 3/5`。

为什么能扔：x 巨大时，x³ 项把 x²、常数项完全淹没了。


</details>

### 15. 【计算机】【C语言部分】 ★ 基础

以下程序输出是（ ）

```c
int i;
for (i = 0; i < 5; i++) {
    if (i == 2) break;
    printf("%d ", i);
}
```

A. 0 1 2　　B. 0 1　　C. 0 1 2 3 4　　D. 2

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

</details>
