### 四、简答题

**36.** 顺序表：随机存取 O(1)，插入删除 O(n) 需移动元素，存储密度高，适合频繁查找、长度确定；链表：顺序存取 O(n)，插入删除 O(1)（已知位置），存储密度低，适合频繁插入删除、长度不定。

**37.** 递归 = 函数调用自身。两个要素：递归出口（终止条件）+ 递归表达式（规模缩小）。优点：程序简洁、逻辑清晰；缺点：效率低（重复计算）、栈开销大（层数深易溢出）。

**38.** struct：各成员独立存储，总大小 = 各成员之和（含对齐），所有成员共存；union：所有成员共享同一块内存，总大小 = 最大成员的大小，只能存一个。

**39.** 冒泡排序：相邻元素两两比较，大的往后交换，每趟把最大元素沉底。第一趟后结果：`[38, 49, 65, 76, 13, 27, 97]`（97 沉底）。

### 五、计算题

**40.** 输出：`15` 和 `5`（sub(5)=5+4+3+2+1=15，i 值传递仍为 5）。

**41.** 12%11=1, 45%11=1→冲突→2, 23%11=1→冲突→2→3, 67%11=1→冲突→2→3→4, 34%11=1→冲突→2→3→4→5, 89%11=1→冲突→2→3→4→5→6。表：[0] [1]12 [2]45 [3]23 [4]67 [5]34 [6]89 [7] [8] [9] [10]

**42.** 第一趟结果：`[27, 38, 13] 49 [76, 97, 65]`。平均 O(n log n)，最坏 O(n²)（已有序时）。

### 六、应用题

**43.** 
```c
#include <stdio.h>
int main() {
    int a[10], i, max, min;
    for (i = 0; i < 10; i++) scanf("%d", &a[i]);
    max = min = a[0];
    for (i = 1; i < 10; i++) {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
    }
    printf("最大=%d, 最小=%d\n", max, min);
    return 0;
}
```

**44.**
```c
#include <stdio.h>
int main() {
    int n, i, sum = 0;
    scanf("%d", &n);
    for (i = 1; i <= n; i++)
        if (i % 3 == 0) sum += i;
    printf("和=%d\n", sum);
    return 0;
}
```

**45.**
```c
#include <stdio.h>
int main() {
    int a, b, c, t;
    scanf("%d%d%d", &a, &b, &c);
    if (a < b) { t = a; a = b; b = t; }
    if (a < c) { t = a; a = c; c = t; }
    if (b < c) { t = b; b = c; c = t; }
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```
