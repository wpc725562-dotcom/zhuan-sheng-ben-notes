第四节语法填空
36. doing
[解析]regret doing sth. 对(做过的)事感到后悔。
37.what
[解析]考查从句: 从句中do 后缺宾语，要选what 做连接词。
38.things
[解析]逐渐适应事情，不止一件事，那么应该用复数形式。
39.joined
[解析]考查时态: then 那时，过去发生的动作应该用过去时。
40.an
[解析]教练是可数名词单数，要加不定冠词，又因为excellence 元音开头，故用an。
41.better
[解析]根据than，可知此处应该用比较级，good 的比较级是better。
42. if
[解析]根据前后两句的关系，可以推断出是条件句，故用if。
43.regularly
[解析]副词修饰动词，所以这里的regular 形容词应变成副词。
44.had run
[解析]考查虚拟语气:在wish 的宾语从句中，对过去的虚拟，谓语动词用had+过去分词。
45.it
[解析]固定短语: give it a try 试一试。
