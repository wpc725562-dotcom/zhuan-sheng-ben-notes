## 🎯 各科推荐学习路径

### 计算机（200分）

```
零基础入门：
  B站：鹏哥C语言 / 郝斌C语言 ─→ 本仓库零基础教程第1-12课 ─→ 动手写代码
  └── 每天至少写3个小程序

系统学习：
  谭浩强《C程序设计》教材 ─→ 本仓库系统笔记1.1-1.11 ─→ 课后习题
  └── 每章结束做教材课后习题

数据结构：
  严蔚敏《数据结构》教材 ─→ 本仓库系统笔记2.1-2.9 ─→ 重点背简答题
  └── 顺序表vs链表、栈vs队列、二叉树遍历必考

刷题冲刺：
  考点拆分 → 历年真题 → 限时模考
  └── 每周至少手写2道编程题
```

### 高数（100分）

```
零基础补高中：
  B站：搜索「高中数学 函数」「三角函数」→ 掌握基本初等函数

系统学习：
  宋浩老师高数课 (同济教材) → 本仓库高数笔记1.1-8.4 → 做课后习题
  └── 每看完一章视频，立刻做对应的习题

刷题冲刺：
  杰哥专升本真题讲解 → 本仓库历年高数真题 → 限时模考
  └── 计算题48分是命根子，每天至少5道计算题
```

### 政治（100分）

```
理解框架：
  徐涛/欢姐视频 → 本仓库政治笔记00-18 → 做思维导图
  └── 先理解框架，再背细节

背诵：
  必背金句(笔记18) → 答题模板(笔记17) → 时事政治(笔记16)
  └── 用关键词记忆法，每个要点记3-5个关键词

刷题：
  历年政治真题 → 练习辨析题/论述题/材料题
  └── 主观题一定要动手写，不要光看
```

### 英语（100分）

```
词汇：
  百词斩/墨墨背单词 → 3400高频词 → 每天20-30词
  └── 坚持每天背，反复刷

语法：
  英语的平行世界（B站） → 本仓库语法笔记 → 语法填空练习
  └── 重点：时态语态、三大从句、非谓语

阅读完形：
  每周2-3篇阅读 → 完形填空专项 → 限时训练
  └── 每篇阅读控制在10分钟内

写作：
  我是瑞斯拜（B站） → 本仓库作文模板 → 每周默写1篇
  └── 书信、议论文各背一个模板
```
