## 二、两种转换方式的差别

| | 文字层直抽 | 视觉模型 OCR |
|:---|:---|:---|
| 适用 | PDF 自带可选中的文字 | 扫描件 / 图片排版 |
| 速度 | 秒级整本 | ~23 秒/页 |
| 成本 | 0 | ~2400 in + 900 out tokens/页 |
| 准确率 | **100%**（原文照搬） | 高，但公式/符号偶有错 |
| 已验证问题 | 无 | 漏负号（`x > -1` → `x > 1`）、残留水印行 |

**结论**：有文字层就别用视觉模型——更慢、更贵，还会引入错误。视觉模型只用于真正读不到字的页面。

## 三、使用建议

1. **高数精编讲义（OCR 版）必须校对后再背**：LaTeX 公式还原度经抽样验收良好，但符号级错误（正负号、上下标）无法自动发现。对照原 PDF 逐章核。
2. **其余 5 本可直接用**：文字层是原文，无转录误差。若发现排版断裂，是 PDF 本身的分栏顺序问题，回原 PDF 看即可。
3. **搜索技巧**：这些 md 已可被 Obsidian / ripgrep 全文检索，比在 PDF 里翻快得多。

## 五、重跑方式

```bash
# 文字层直抽（改脚本里的 WATERMARK/PAGE_NO 规则后重跑）
python scripts/pdf_to_md.py --force

# 视觉模型 OCR（支持断点续跑，中断后重跑会跳过已完成页）
python scripts/pdf_vision_ocr.py \
  --pdf "C:\Users\Administrator\Desktop\2026讲义与知识汇编\【精编讲义】2026广东专插本《高等数学 》.pdf" \
  --out "资料/2026讲义/【精编讲义】2026广东专插本《高等数学》.md" \
  --dpi 150
```

OCR 引擎为 `baiapi/qwen3.8-flash`（2026-09-03 实测具备视觉能力）。若余额耗尽脚本会以 exit 3 安全停止并保留进度；跑完会自动按页号重排，补跑失败页不会打乱顺序。

脚本会丢弃机构水印行与纯页码行；`--probe` 可只跑 1 页做质量验收。
