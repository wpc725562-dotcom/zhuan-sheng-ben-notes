## 二、卡片模板（用什么模型）

**推荐：内置「问答题」模型（正面/背面）**，字段标准命名：

| 字段 | 内容 | 示例 |
|:---|:---|:---|
| **正面** | 题目 + 题干（写清条件） | 【错题·极限】求 $\displaystyle\lim_{x\to+\infty}(\sqrt{x^2+x}-x)$ |
| **背面** | 答案 + 关键步骤 + **易错点** | 1/2。有理化：分子分母同乘 $\sqrt{x^2+x}+x$；**易错**：别直接写 $\infty-\infty=0$ |

> 为什么不用「填空题」？高数错题多为计算/推导类，开放式的「问答题」能逼自己先动笔推导再对答案，符合提取练习原则。
> ⚠️ 中文版 Anki 的笔记类型名是中文的：`问答题` = Basic，`填空题` = Cloze。

**卡片要写什么（三要素缺一不可）**：

1. **完整题干**——复习时能脱离原卷独立重做
2. **关键步骤**——不是只写答案，写「怎么想到这个方法」
3. **易错点/坑**——用自己的话写当初为什么错（这是"错题卡"的灵魂）

**好卡示例**：

```
正面：【易错·极限】x→+∞ 时 √(x²+x) − x = ？
背面：1/2。
步骤：乘共轭 (√(x²+x)+x) → 分子变 x → 除以 x → 1/(√(1+1/x)+1) → 1/2。
易错点：我当初写成 ∞−∞=0；要想到"乘共轭有理化"。
```

## 三、用 AnkiConnect 创建卡片的步骤

> Anki 桌面端需先打开，AnkiConnect 监听 `http://127.0.0.1:8765`。

### 0️⃣ 必读：Windows 中文编码避坑（实测教训）

⚠️ **在 Windows 命令行直接 `curl -d "中文JSON"` 会按 GBK 编码发送，导致 AnkiConnect 报 `'utf-8' codec can't decode` 甚至让 Anki 崩溃。**

**正确姿势**：把 JSON 存成 UTF-8 文件，用 `--data-binary @文件` 发送。下面的命令全部这样写。

### 1️⃣ 确认 AnkiConnect 在线

```bash
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" \
  -d '{"action":"version","version":6}'
# 期望：{"result": 6, "error": null}
```

### 2️⃣ 查看现有牌组 / 模型

```bash
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" \
  -d '{"action":"deckNames","version":6}'        # 牌组列表
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" \
  -d '{"action":"modelNames","version":6}'       # 模型列表（含"问答题"）
```

### 3️⃣ 建分章子牌组（可选，按 8 章各建一次）

```bash
cat > deck.json <<'EOF'
{"action":"createDeck","version":6,"params":{"deck":"专升本-高数错题::第一章 函数与极限"}}
EOF
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" --data-binary @deck.json
```

### 4️⃣ 添加错题卡（核心）

把下面 JSON 里的**正面/背面/标签**换成你的题，存为 `card.json`：

```bash
cat > card.json <<'EOF'
{
  "action": "addNote",
  "version": 6,
  "params": {
    "note": {
      "deckName": "专升本-高数错题::第一章 函数与极限",
      "modelName": "问答题",
      "fields": {
        "正面": "【易错·极限】x→+∞ 时 √(x²+x) − x = ？",
        "背面": "1/2。乘共轭 (√(x²+x)+x) 有理化；易错：别把 ∞−∞ 当 0。"
      },
      "tags": ["高数错题", "第一章", "极限"]
    }
  }
}
EOF
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" --data-binary @card.json
# 期望：{"result": 1837xxx（新笔记ID）..., "error": null}
```

### 5️⃣ 验证卡片入库

```bash
cat > check.json <<'EOF'
{"action":"findNotes","version":6,"params":{"query":"tag:高数错题"}}
EOF
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" --data-binary @check.json
# 返回 noteId 列表；再对 noteId 调 notesInfo 可看完整内容
```

## 四、批量建卡（错题多时）

一次多题：用 `addNotes`（复数），notes 数组里放多张卡：

```bash
cat > batch.json <<'EOF'
{
  "action": "addNotes",
  "version": 6,
  "params": {
    "notes": [
      {"deckName":"专升本-高数错题::第一章 函数与极限","modelName":"问答题",
       "fields":{"正面":"题A","背面":"答A+易错点"},"tags":["高数错题","第一章"]},
      {"deckName":"专升本-高数错题::第二章 一元函数微分学","modelName":"问答题",
       "fields":{"正面":"题B","背面":"答B+易错点"},"tags":["高数错题","第二章"]}
    ]
  }
}
EOF
curl -X POST http://127.0.0.1:8765 -H "Content-Type: application/json" --data-binary @batch.json
```

> 单张写好了再上批量。批量返回 `[noteId1, noteId2, …]`，`null` 表示该张失败（字段空之类）。

## 五、错题进 Anki 的「节奏规则」（对接周计划）

| 时机 | 动作 |
|:---|:---|
| 每次刷题/周测后 | 当天把错题做成卡（10-20 分钟，见 [[../plan/阶段学习计划|计划]] 每周模式③） |
| 每周日 | 清积压：本周错题全部入库，>10 张就用 `addNotes` 批量 |
| 每天碎片时间 | Anki 自动复习，目标日复习 ≤15 分钟 |
| 每周自测前 | 先过一遍本周章节的 Anki 卡，再动笔周测 |

**卡片数量节奏**：基础期每周 ≤10 张新卡、强化期 ≤15 张、冲刺期不再加新卡只复习旧卡。

## 六、维护规则

1. **卡片要「瘦」**：一张卡只考一个点；综合题拆成 2-3 张卡
2. **错了再卡**：复习时没做对 → 按 Anki 的"重来"（Again）处理，别改卡
3. **易错点持续更新**：同一考点二错，直接在背面追加一句"又错了！这次是因为…"
4. **过期清理**：考后（2027 年 4 月起）按需归档，不影响考试前
