# 2.9 洛必达法则

> **这句人话**：当极限是 $\frac00$ 或 $\frac{\infty}{\infty}$ 时，对分子分母分别求导，再求极限，往往就做出来了！洛必达就是"分式求极限卡住了→各求各的导→再算"。

## 一、 考点全覆盖

### 使用条件
1. $\frac00$ 或 $\frac{\infty}{\infty}$ 型未定式
2. 分子分母都在 $x_0$ 附近可导
3. 求导后的极限存在（或为 $\infty$）

### 公式
$$\lim_{x\to x_0}\frac{f(x)}{g(x)} = \lim_{x\to x_0}\frac{f'(x)}{g'(x)}$$

### 其他未定式转化
- $0\cdot\infty$ → 写成 $\frac0{1/\infty}$ 或 $\frac\infty{1/0}$
- $\infty-\infty$ → 通分或倒代换
- $1^\infty, 0^0, \infty^0$ → 取 $\ln$ 转化

## 二、 手把手例题

**例 1** $\lim_{x\to0}\frac{\sin x}{x}$（洛必达法）
> 【解】$\frac00$ 型，洛必达：$\lim_{x\to0}\frac{\cos x}{1}=1$。

**例 2** $\lim_{x\to\infty}\frac{\ln x}{x}$
> 【解】$\frac{\infty}{\infty}$ 型，洛必达：$\lim_{x\to\infty}\frac{1/x}{1}=0$。

**例 3** $\lim_{x\to0^+} x\ln x$（$0\cdot\infty$ 型）
> 【解】写成 $\lim_{x\to0^+}\frac{\ln x}{1/x}=\frac{-\infty}{\infty}$，洛必达：$\lim_{x\to0^+}\frac{1/x}{-1/x^2}=\lim_{x\to0^+}(-x)=0$。

## 三、 闭卷训练营

1. 洛必达适用于哪两种未定式？
2. $0\cdot\infty$ 型怎么转化？
3. $\lim_{x\to0}\frac{1-\cos x}{x^2}$ 用洛必达求。
4. 洛必达失效的情况有哪些？

> **点开看答案**
> 1. $\frac00$ 和 $\frac{\infty}{\infty}$；2. 写成 $\frac0{1/\infty}$ 或 $\frac\infty{1/0}$；3. $\lim_{x\to0}\frac{\sin x}{2x}=\frac12$；4. 求导后极限不存在（但非 $\infty$）或循环。

## 四、 易错雷区

- 洛必达**不是万能**的，循环求导或极限不存在时换方法
- 先判断是否 $\frac00$ 或 $\frac{\infty}{\infty}$，不是就不能用
- 每次洛必达前检查是否还能用，可以多次使用
