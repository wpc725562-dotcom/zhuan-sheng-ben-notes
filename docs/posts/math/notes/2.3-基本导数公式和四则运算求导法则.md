# 2.3 基本导数公式和四则运算求导法则

> **这句人话**：导数公式就像九九乘法表——背得滚瓜烂熟，做题才能快到飞起。四则运算法则记住口诀：**前导后不导 + 前不导后导**（乘法），**上导下不导 - 上不导下导除以分母平方**（除法）。

## 一、 基本求导公式表（必背！）

### 幂与常数
| 原函数 | 导数 |
|:---|:---:|
| $C$ | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\frac1x$ | $-\frac1{x^2}$ |
| $\sqrt{x}$ | $\frac1{2\sqrt{x}}$ |

### 三角
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\cot x$ | $-\csc^2 x$ |

### 反三角
| $\arcsin x$ | $\frac1{\sqrt{1-x^2}}$ |
| $\arccos x$ | $-\frac1{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\frac1{1+x^2}$ |

### 指数对数
| $e^x$ | $e^x$ |
| $a^x$ | $a^x\ln a$ |
| $\ln x$ | $\frac1x$ |
| $\log_a x$ | $\frac1{x\ln a}$ |

### 四则运算法则
- $(u\pm v)'=u'\pm v'$
- $(uv)'=u'v+uv'$
- $(\frac{u}{v})'=\frac{u'v-uv'}{v^2}$

## 二、 手把手例题

**例 1** $f(x)=x^2\ln x$ 求导。
> 【解】乘法法则：$(x^2)'\ln x + x^2(\ln x)' = 2x\ln x + x^2\cdot\frac1x = 2x\ln x + x$

**例 2** $f(x)=\frac{x^2+1}{x^2-1}$ 求导。
> 【解】先化简：$f(x)=1+\frac{2}{x^2-1}$，再求导：$f'(x)=0+2\cdot\frac{-2x}{(x^2-1)^2}=\frac{-4x}{(x^2-1)^2}$

## 三、 闭卷训练营

1. $(\tan x)'=$ ? 2. $(\ln x)'=$ ? 3. $(a^x)'=$ ?
4. 求 $f(x)=\frac{x}{x+1}$ 的导数。
5. 分式化简再求导能省多少计算量？

> **点开看答案**
> 1. $\sec^2 x$；2. $\frac1x$；3. $a^x\ln a$；4. $\frac1{(x+1)^2}$；5. 经常能省一半。

## 四、 易错雷区

- $\tan x$ 导数不是 $\sec x$，是 $\sec^2 x$！
- 除法法则分子是 $u'v-uv'$，**减号方向别反**
- 能化简的先化简，别硬套除法法则
