# 3.3 第一类换元法（凑微分法）

> **这句人话**：凑微分就是"看穿复合函数"——如果被积函数是 $f(\varphi(x))\cdot\varphi'(x)$ 的形式，就令 $u=\varphi(x)$，把 $\varphi'(x)dx$ 看成 $du$，积分就简化了。

## 一、 考点全覆盖

### 核心公式
$$\int f[\varphi(x)]\varphi'(x)dx = \int f(u)du \quad\text{其中 } u=\varphi(x)$$

### 常用凑微分形式
- $\int f(ax+b)dx = \frac1a\int f(ax+b)d(ax+b)$
- $\int f(x^n)x^{n-1}dx = \frac1n\int f(x^n)dx^n$
- $\int f(\sin x)\cos x dx = \int f(\sin x)d(\sin x)$
- $\int f(\ln x)\frac1x dx = \int f(\ln x)d(\ln x)$

## 二、 手把手例题

**例 1** $\int \cos(2x+1)dx$
> 【解】令 $u=2x+1$，$du=2dx$，$dx=\frac12du$。原式 $=\frac12\int \cos u du = \frac12\sin(2x+1)+C$

**例 2** $\int \frac{\ln x}{x}dx$
> 【解】令 $u=\ln x$，$du=\frac1x dx$。原式 $=\int u du = \frac12(\ln x)^2+C$

## 三、 闭卷训练营

1. 凑微分的核心思路是什么？
2. $\int e^{2x}dx =$ ?
3. $\int \sin x\cos x dx =$ ?

> **点开看答案**
> 1. 令 $u=\varphi(x)$，把 $\varphi'(x)dx$ 凑成 $du$；2. $\frac12 e^{2x}+C$；3. $\frac12\sin^2 x+C$ 或 $-\frac12\cos^2 x+C$

## 四、 易错雷区

- 凑完 $du$ 别忘了补系数（如 $dx\to\frac1a du$）
- 检查凑完后积分变量是否统一
