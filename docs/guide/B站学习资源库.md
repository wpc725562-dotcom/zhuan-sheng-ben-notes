## 一、高等数学（主战场 · 100 分）

| UP 主 | 用途 | 用法 |
|:---|:---|:---|
| **杰哥专升本** | 专升本真题、考点拆解 | 主攻：跟他的真题讲解，按考点刷 |
| **宋浩老师** | 概念讲解（大学高数） | 辅助：概念不懂时看，别沉迷（看视频≠做题） |
| 汤家凤/张宇（如有余力） | 强化计算 | 冲刺期可补充计算题量 |

**实体书**：《广东省专升本应试宝典·高等数学》
**重点章节**（按 2026 考情）：函数与极限 → 导数与微分 → 一元积分 → 微分方程 → 向量与空间解析几何 → 多元微分 → 二重积分 → 级数
**分值**：选择 5×3 + 填空 5×3 + 计算 8×6 + 综合 2（10+12）= 100 分。**计算题 48 分是命根子。**

## 二、C 语言 / 数据结构（主战场 · 200 分！）

| UP 主 | 用途 | 用法 |
|:---|:---|:---|
| **鹏哥C语言** | 系统学习 C 语言 | 主攻：从零系统学，配合敲代码 |
| **C语言编程学习** | 专升本真题 | 刷真题、手写代码 |

**实体书**：《应试宝典·计算机基础与程序设计》
**重点章节**：语法 → 控制结构 → 数组 → 函数 → 指针（难点）→ 结构体 → 文件；数据结构：线性表 → 栈/队列 → 树/二叉树 → 图 → 查找 → 排序
**分值**：单选 20×3 + 判断 10×2 + 填空 5×4 + 简答 4×10 + 计算 3×10 + 应用 3×10 = 200 分。**应用题 30 分要手写代码，必须真机练习。**

> ⚠️ **2026 改革信号**：2026 是广东专升本"考试形式优化"第一年，题型**含"改错题"**，2027 大概率延续新框架。别只按旧六大题型练。
