# 资料边界（必读）

1. 考试院**不公开**原卷 PDF；网络流传多为**考生回忆版** / 培训机构汇编。
2. 本库保证：**广东题型结构 + 得分逻辑 + 可默写解法**。
3. 措辞若与正版真题册不一致，**以纸质/当次正式卷为准**。
4. 仅供个人学习，请勿当泄题卷传播。
5. 2024 计算机全卷详解体例参考：[Sakiko · 2024 真题详解](https://sakikoblog.info/posts/2024-zhuanchaben-c-programming)。
5.1. 学习手册/站点结构借鉴来源详见 [📚 学习博客借鉴清单](/guide/学习博客借鉴)（日语/高数/英语/政治/计算机六板块 20+ 站点）。
6. **英语 2008–2024**：站点内嵌 **按年拆分的 PDF 原卷**（`/papers/english/年份-full.pdf`），浏览器直接预览；另附 OCR 全文便于复制。OCR 可能粘连空格，**以 PDF 预览为准**。
7. **高数 / 政治 / 计算机**：站点也已内嵌原卷 PDF —— 高数（`/papers/math/2003-2019-高数合集.pdf`、`/papers/math/2020.pdf`）、政治（`/papers/politics/2012-2019-政治合集.pdf`、`/papers/politics/2020.pdf`）、计算机（`/papers/computer/2021–2024.pdf`，本地 OCR 文本版）。供核对卷面，高数/政治为扫描合集版、计算机为文本抽取版。
