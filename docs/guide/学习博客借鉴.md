# 学习博客借鉴清单

> 本站学习手册的**结构灵感来源**。借鉴的是「**怎么组织内容**」而不是「照抄内容」——所有正文均为本站自写，按广东专升本考纲口径整理。
>
> 首次借鉴：[Sakiko 标日同步手册](https://sakikoblog.info/learn/)（逐课知识骨架 + 复习任务）。本文档是 2026-08 大规模搜索后整理的扩展清单。

## 一句话方法

优秀学习博客的共同点是：**按教材顺序逐课/逐章组织，每节有「知识骨架 + 例题/考点 + 复习任务」**，且都考虑「零基础读者怎么读得懂」。本站四科学习手册即采用此框架。

## 🇯🇵 日语板块借鉴（最贴近 Sakiko）

### 告你日语 —— 标日逐课笔记站

- **站点**：[ja.tellyouwhat.cn](https://ja.tellyouwhat.cn/) ｜ 开源 [harborzeng/tellyou-nihongo](https://github.com/harborzeng/tellyou-nihongo)（Hugo + Doks 构建）
- **值得借鉴**：
  1. 首页一个**「从零开始」大按钮**直接指向五十音 → 引导零基础用户
  2. **六卡片导航**：学习笔记 / 学习文章 / 考前复习 / 故事分享 / 动漫影视 / 单词语法对比
  3. 笔记**按教材分册**（初上 / 初下 / 中上 / 中下），每册再按课
  4. **单词语法对比学习**：对比近似单词、相似语法的细微差别
  5. 语法按册汇总（N5→N1 例句大全）
- **本站可借鉴**：日语板块增加「五十音一键入口」大按钮、语法对比表。

### 三十的博客 —— Hugo 日语笔记

- **站点**：[wanglei.live/japanese/](https://wanglei.live/japanese/)
- **值得借鉴**：日语笔记按知识点拆篇（动词相关 / 形容词变形 / KoSoADo 系列 / 形容词分类），**一个知识点一篇文章**，方便单独查阅。

### feizao825 —— 日语学习计划博客

- **站点**：[feizao825.github.io](https://feizao825.github.io/2025/04/06/日语学习/)
- **值得借鉴**：给出**分阶段学习计划**（五十音 → 初步学习 1 个月用《大家的日语》→ 单词计划每日 50-200 词），先搭框架后巩固。

### iKnow's blog —— 新标日学习笔记

- **站点**：[iknow.fun](https://iknow.fun/2021/06/07/xin-biao-zhun-ri-ben-yu-xue-xi-bi-ji/)
- **值得借鉴**：**表达及词语讲解**按「结合课文具体内容」讲解，而非罗列全部含义；例句中日文汉字都注假名。

### Shawn Wang —— 标日按课语法总结

- **站点**：[github.com/wizicer/LearnJapan](https://github.com/wizicer/LearnJapan)
- **值得借鉴**：以《新版中日交流标准日本语》为纲，**逐课记录**的学习笔记本（Jupyter 格式，可运行）。

### 日语迷 —— 日语学习博客

- **站点**：[riyumi.com](https://riyumi.com/)
- **值得借鉴**：**月度回顾**文章（每月复盘学了什么、进度如何），养成「记录-回顾」闭环。

## 📐 高数板块借鉴

### 荒原之梦 —— 考研数学笔记汇总

- **站点**：[zhaokaifeng.com](https://zhaokaifeng.com/%E8%80%83%E7%A0%94%E6%95%B0%E5%AD%A6%E9%AB%98%E7%AD%89%E6%95%B0%E5%AD%A6%E7%AC%94%E8%AE%B0%E6%B1%87%E6%80%BB/)
- **值得借鉴**：笔记不是课本复述，而是**「分析性文章」**——包含自己的理解和想法。高数笔记关键是讲清「为什么」。

### Xenny 的博客 —— 考研高数笔记

- **站点**：[xenny.wiki](https://xenny.wiki/posts/note/postgraduate/advanced_math.html)
- **值得借鉴**：按**主题/题型**组织复习要点（极限 / 导数 / 中值定理 / 微分方程 / 积分 / 级数 / 多元微分 / 二重积分…），适合考前快速过。

### ixtwuko —— 博客园高数笔记

- **站点**：[cnblogs.com/ixtwuko](https://www.cnblogs.com/ixtwuko/p/advanced-mathematics.html)
- **值得借鉴**：**公式多导致单篇渲染吃力** → 按章节拆成多篇（P00 基础补充 / P01 函数极限连续 / P02 一元微分…）。本站高数手册按 12 章组织正是同样思路。

### Canis 考研数学2 —— Obsidian 发布笔记

- **站点**：[publish.obsidian.md/gee-math-2](https://publish.obsidian.md/gee-math-2/%E6%AC%A2%E8%BF%8E%EF%BC%81)
- **值得借鉴**：用 **Obsidian 双链组织数学笔记**并发布，GPL-3.0 开源可对照学习。与本站 Obsidian 本地库工作流同源。

### 知乎 · 专升本高等数学笔记

- **站点**：[zhuanlan.zhihu.com/p/426358616](https://zhuanlan.zhihu.com/p/426358616)
- **值得借鉴**：**逐章整理**并标注「重要考点」——如第一章「定义域求解」，最贴合专升本考纲颗粒度。

## 🇬🇧 英语板块借鉴

### hzpt-inet-club/english-note —— 从0学英语语法

- **站点**：[github.com/hzpt-inet-club/english-note](https://github.com/hzpt-inet-club/english-note)
- **值得借鉴**：把复杂语法**「掰碎了」**逐条讲，零基础友好。结构：词性 → 句子成分 → 时态 → 从句。

### welives —— 新概念英语学习笔记

- **站点**：[welives.github.io](https://welives.github.io/blog/language/english/nce/one.html)
- **值得借鉴**：**知识点快速索引表**——时态（现在进行时/一般现在时…/现在完成时）、There be、被动语态、各类问句一表列全，复习极快。

### English Hub —— 私人英语学习日志

- **站点**：[liantianno1.github.io/english_study_web](https://liantianno1.github.io/english_study_web/)
- **值得借鉴**：**每日新词 + 间隔复习 + 错题本 + 语法关卡**，本地优先离线可用。与本站 Anki 卡片链路互补。

### YJango —— English 语法整理

- **站点**：[yjango.github.io/ENGLISH](https://yjango.github.io/ENGLISH/)
- **值得借鉴**：语法按**主题归纳**（人称代词/介词/动名词/不定式/句子类型/时态/定语从句…），归纳度高。

### LexShelf —— 单词学习书架

- **站点**：[jerryil.github.io/lexshelf](https://jerryil.github.io/lexshelf/)
- **值得借鉴**：单词按**主题/词性分类**成「书架」，一本书一套进度，配插图、点读、测验。

### jinronga —— 英语单词整理

- **站点**：[jinronga.github.io/english-words](https://jinronga.github.io/english-words/)
- **值得借鉴**：**分类词汇表**（如 TEM-8 分类词汇），按考试等级拆分。
