# 标日同步语法与词汇手册 📚

这是一套面向中文母语者的三卷本日语学习笔记，沿用《新版中日交流标准日本语》从初级到高级的学习顺序，逐课整理语法骨架、核心词汇、原创例句和复习任务。

> 本手册是独立编写的配套复习资料，不收录或替代原教材的课文、录音、练习及完整生词表。不同印次的细节可能略有差异，学习时请与手中的正版教材对照。

## 入门必读

### [日语动词与形容词：分类判断和变形总览](./conjugation-guide)

先弄懂 `动1／动2／动3` 与 `形1／形2` 的区别，再进入逐课学习。这里集中整理了判断方法、易错例外、`ます形／ない形／て形／た形／可能形／被动形／使役形` 等变形规则，以及两类形容词的完整活用对照。

## 三卷目录

### [第一卷：初级篇（第 1～48 课）](./elementary)

从判断句、指示词和基础助词开始，系统掌握动词变形、形容词、授受关系、条件、可能、被动、使役与初级敬语。学完后建立 N5～N4 的语法和生活词汇基础。

### [第二卷：中级篇（第 1～32 课）](./intermediate)

从句子过渡到篇章，重点学习复合助词、书面表达、推断、限定、原因、让步和谈话组织。上、下两部分大致衔接 N3 与 N2。

### [第三卷：高级篇（第 1～24 课）](./advanced)

围绕社会、文化、环境、商务等主题，整理高级书面语、语气控制、逻辑连接和近义表达辨析，目标是提升 N1 阶段的阅读、听力与写作能力。

## 每课怎么学

1. 先读“语法地图”，确认这课解决什么表达问题。
2. 朗读原创例句，替换其中的人物、时间和对象。
3. 把核心词汇按搭配记忆，不孤立背中文释义。
4. 不看页面复述语法，并完成课末的一句话任务。
5. 每四课进行一次回顾，把容易混淆的表达放在一起比较。
